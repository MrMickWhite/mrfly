# MR.MICK FLY

Servicio técnico de drones en la provincia de Santa Elena. Atiendo en Salinas,
La Libertad y Santa Elena, y con coordinación previa en el resto del Ecuador.

## En qué ayudo

- Revisión y diagnóstico cuando el dron no enciende o no vuela bien
- Mantenimiento preventivo y limpieza profunda (polvo, salitre, humedad del mar)
- Reparación de hardware: motores, hélices, placas, cámara y gimbal
- Problemas de calibración y firmware

## Sobre este repositorio

Es la página web del servicio (fly.mrmickwhite.com): un sitio estático en HTML,
CSS y JavaScript que explica lo que hago y deja el contacto a mano.
